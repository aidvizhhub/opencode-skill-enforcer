# Обзор

Плагин для OpenCode V2. Держит скиллы и файлы-справочники в контексте, заставляет
агента ими пользоваться и напоминает следовать тому, что уже загружено.

Один файл кода — `index.ts` в корне проекта.

## Три механизма

| Механизм | Где | Что делает |
| --- | --- | --- |
| Правило-напоминание | `session.hook("context")` | на каждом шаге модели добавляет в system короткое правило: база в контакте, сколько рабочих загружено, «сверься и добери» |
| Цепка | `session.hook("prompt")` | на входе сообщения кладёт в контекст базовый набор общения и/или скиллы по смыслу, а также куски из файлов-справочников |
| Счётчик | `tool.hook("execute.before")` | считает вызовы инструмента `skill`, чтобы правило знало, что уже загружено |

Правило работает всегда и не выключается. Цепка управляется опциями.

## Что включено по умолчанию

| Механизм | Дефолт движка | В конфиге пользователя |
| --- | --- | --- |
| Скиллы: база + добор | включено | включено |
| Справочники (`documents`) | выключено (`[]`) | включено (`~/AGENTS.md`) |
| Семантика (`docLlm`) | выключено (`false`) | включено |

«Из коробки» плагин цепляет только скиллы. Справочники и семантику включают в конфиге.

## Режимы цепки

- всё (по умолчанию): база + добор;
- только база: `{ "attachAlways": true, "attachPicked": false }`;
- только напоминание, без тел: `{ "autoAttach": false }`.

## База общения

`alwaysSkills` — структура ответа (`result-first`), живой контакт (`dialog-humanity`),
язык без нейрослопа (`anti-ai-sludge`). Весит около 26 КБ, цепляется один раз за сессию,
дальше лежит в истории.
